 FENÊTRES
   Super + W                 fermer la fenêtre
   Super + F / M             plein écran / maximiser
   Super + T                 basculer en fenêtre flottante
   Super + Y                 activer/désactiver le tiling
   Super + O                 basculer la division horizontale/verticale
   Super + Flèches           déplacer le focus
   Super + Maj + Flèches     déplacer la fenêtre
   Super + X                 échanger les fenêtres
   Super + S                 empiler les fenêtres (onglets)

 ESPACES DE TRAVAIL
   Super + 1…9               aller à l'espace de travail
   Super + Maj + 1…9         envoyer la fenêtre vers l'espace de travail

 APPLICATIONS
   Super                     lanceur
   Super + Alt + Espace      lanceur d'applications
   Super + Entrée            terminal
   Super + B / E             navigateur / fichiers
   Super + Maj + N / T       neovim / btop

   Super + Maj + A           agent d'IA local
