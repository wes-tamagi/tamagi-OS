 WINDOWS
   Super + W                 close window
   Super + F / M             fullscreen / maximize
   Super + T                 toggle floating window
   Super + Y                 turn tiling on/off
   Super + O                 toggle horizontal/vertical split
   Super + Arrows            move focus
   Super + Shift + Arrows    move the window
   Super + X                 swap windows
   Super + S                 stack windows (tabs)

 WORKSPACES
   Super + 1…9               go to workspace
   Super + Shift + 1…9       send the window to the workspace

 APPLICATIONS
   Super                     launcher
   Super + Alt + Space       application launcher
   Super + Enter             terminal
   Super + B / E             browser / files
   Super + Shift + N / T     neovim / btop
   Super + Shift + G / D     lazygit / databases (tamagi-db)
   Super + Shift + O / M     OnlyOffice / Mission Center
   Super + Shift + W         Windows 11 (container)

 Tamagi
   Super + Space             Tamagi menu (command palette)
   Super + A                 quick actions (one key)
   Super + Shift + A         local AI agent
   Super + K                 this list
   Super + Shift+Ctrl+Space  next theme

 SYSTEM
   Super + Esc               lock the screen
   Print                     screenshot
   Shift + Print             copy text from an area (OCR)
   Alt + Print               record the screen / stop
   Super + Ctrl + E          emoji
   Super + Ctrl + R          reminder
   Super + Ctrl + Space      switch keyboard layout
